# 💸 Student Expense Tracker

> Track it. Understand it. Control it.

A simple Python-based expense tracker built to help students keep an eye on their daily spending without making money management complicated.

## ⚡ What Can It Do?

- ➕ Add daily expenses
- 🏷️ Categorize spending
- 📋 View recorded expenses
- 💰 Calculate total spending
- 🖥️ Simple command-line interface

## 🧠 Built With

**Python**

Using:
- Lists & Dictionaries
- Loops
- Conditional Statements
- User Input
- Basic Data Processing
